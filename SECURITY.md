# Política de Segurança

## Versões Suportadas

Esta seção informa quais versões do nosso projeto estão recebendo atualizações de segurança.

| Versão | Suportada |
| :--- | :--- |
| 1.0.x | ✅ Sim |
| < 1.0 | ❌ Não |

## Reportando Vulnerabilidades

Se você encontrar alguma vulnerabilidade, por favor nos reporte seguindo as instruções abaixo. 

Envie um e-mail para **israpvphg25@gmail.com** com detalhes sobre a vulnerabilidade. Para agilizar a análise, inclua o máximo de informações possível, como:

* **Descrição:** Explique qual é a vulnerabilidade e o que ela afeta.
* **Versão afetada:** Indique em qual versão do SafeStreets você encontrou o problema.
* **Passos para reproduzir:** Liste o passo a passo exato para que nossa equipe consiga simular o problema.
* **Impacto identificado:** Descreva o que um invasor poderia fazer explorando essa falha.

> **Observação:** No momento, não oferecemos recompensas financeiras (programas de *Bug Bounty*) por vulnerabilidades relatadas.

## Divulgação

Estamos comprometidos em:
* Validar e corrigir vulnerabilidades de forma responsável.
* Notificar os usuários quando uma atualização de segurança for lançada.
* Reconhecer formalmente os pesquisadores de segurança e desenvolvedores que ajudam a melhorar a segurança do **SafeStreets**.
