## 📔 O que foi feito?

### 📌 Protótipo de Alta Fidelidade

A equipe desenvolveu um protótipo de alta fidelidade da plataforma SafeStreets com o objetivo de mostrar as funcionalidades, a identidade visual e experiência do usuário. Por meio deste wireframe a equipe conseguiu representar de maneira visual o sistema da página web antes do desenvolvimento definitivo.

**Link:** [Protótipo de alta fidelidade](https://github.com/unb-mds/2026-1-SafeStreets/issues/36)

### 📌 Documentação (MkDocs)

Foi implementado o gitpages através do MkDocs, onde os desenvolvedores e usuários poderão ter acesso a dados da equipe e documentação utilizada, facilitando a consulta e entendimento da arquitetura do projeto.

**Link:** [Implementação do portal de documentação](https://github.com/unb-mds/2026-1-SafeStreets/issues/37)

### 📌 Diagrama de infraestrutura

Foi realizado o diagrama de arquitetura do sistema com o objetivo de representar de forma clara os componentes principais, as responsabilidades e a comunicação entre eles. O diagrama é uma ferramenta que ajuda a equipe a visualizar a estrutura do projeto, incluindo frontend, backend, banco de dados e integrações (APIs).

**Link:** [Diagrama de infraestrutura](https://github.com/unb-mds/2026-1-SafeStreets/issues/19)

### 📌 Implementação da API

A equipe implementou uma API para o sistema, permitindo a comunicação entre o front-end e o back-end de forma estruturada e escalável.

**Link:** [Implementação da API](https://github.com/unb-mds/2026-1-SafeStreets/pull/26)

### 📌 Story Map

O time criou o story map do projeto, acrescentando de forma clara e organizada os Epics, as funcionalidades definidas para o sistema, as histórias de usuário e os critérios de aceitação.

**Link:** [Story map - Figma](https://www.figma.com/board/13SnyvGleeaYsubnOhMeYk/Template-MDS-Squad-1?t=dWstsfMDvKQHpAR4-1)

### 📌 Implementação banco de dados

Foi realizada uma implementação inicial do banco de dados do projeto SafeStreets através da utilização de tecnologias como PostgreSQL em ambiente isolado (Docker). Também foi estabelecida a integração com o backend com SQLAlchemy (ORM) e driver Psycopg2.

**Link:** [Implementação banco de dados](https://github.com/unb-mds/2026-1-SafeStreets/pull/31)

### 📌 Definições do front-end

Foram definidas as tecnologias utilizadas no desenvolvimento do front-end do SafeStreets, bem como as justificativas para cada escolha. O objetivo é garantir um sistema moderno, escalável e de fácil manutenção.

**Link:** [Definições do frontend](https://github.com/unb-mds/2026-1-SafeStreets/issues/29)

### 📌Kanban

Foi estruturado um quadro kanban do projeto, com a finalidade de garantir maior clareza no fluxo de trabalho da equipe, visibilidade das tarefas e melhoria na produtividade do time.

**Link:** [Organização do Kanban](https://github.com/unb-mds/2026-1-SafeStreets/issues/29)

### 📌Planejamento e entregas semanais

Foi realizada a organização das atividades, estudos, documentação e implementações que a equipe tem realizado durante o período da release 1, as entregas foram estruturadas semanalmente e acrescentadas no template do figma da SafeStreets (Squad 1)

**Link:** [Planejamento e entregas semanais](https://github.com/unb-mds/2026-1-SafeStreets/issues/38)

### 📌Rotas para API

Foi implementada dentro do backend módulos específicos na pasta routers para as rotas que se encontravam no arquivo principal, com o objetivo de evitar conflitos de código no main.py permitindo que o projeto cresça de forma escalável.

**Link:** [Modularização de rotas com APIRouter](https://github.com/unb-mds/2026-1-SafeStreets/pull/41)
