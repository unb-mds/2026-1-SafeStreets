<p class="intro-text">
  O <strong>SafeStreets</strong> é uma aplicação de ponta voltada ao monitoramento e mapeamento dinâmico de riscos urbanos. A partir do processamento e da análise automatizada de notícias públicas e de dados oficiais de segurança, a plataforma oferece uma visão clara, centralizada e georreferenciada de ocorrências críticas nas cidades. Nosso objetivo é promover a conscientização cidadã e subsidiar tomadas de decisões conscientes no cotidiano urbano, além de fornecer uma API robusta para plataformas parceiras.
</p>
